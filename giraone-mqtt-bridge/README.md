# Home Assistant App: GiraOneMqttBridge

This Application uses the [giraone-mqtt-bridge](https://github.com/matgroe/giraone-mqtt-bridge) to integrate the [GiraOne SmartHome](https://www.gira.de/produkte/systeme/gira-one) 
into Home Assistant via MQTT.
